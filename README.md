# 📚 منصة البكالوريا الذكية

**مشروع مفتوح المصدر لتنظيم محتوى البكالوريا السورية.**

## 🚀 الميزات
- 8 مواد دراسية كاملة (رياضيات، فيزياء، كيمياء، علوم، عربي، ديانة، إنجليزي، فرنسي).
- تتبع التقدم المحلي بدون إنترنت (Local Storage).
- تصميم متجاوب مع جميع الأجهزة.
- نظام شارات للإنجاز والتحفيز.
- خطة يومية ذكية لحساب الدروس المتبقية.
- دعم PWA للتثبيت على الجوال.

## 🔧 التقنيات المستخدمة
- HTML5 / CSS3
- JavaScript (ES6+)
- Local Storage API
- Font Awesome Icons
- Google Fonts
- GitHub Pages

## 📦 التثبيت والتشغيل
```
git clone https://github.com/HussenAldhb/bac-platform.git
cd bac-platform
```
ثم افتح `index.html` في متصفحك.
